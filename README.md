# ग्राम-सेवा (GramSeva) - Smart Rural Intelligence Mobile App

> **Live Mandi Rates • Weather Radar • Pincode & Village Services**  
> Developed by **ChittorTech** for Farmers, Traders & Citizens across Rajasthan & India.

---

## 📱 Tech Stack & Architecture

* **Framework:** 100% Native **Kotlin (2.0+)** with **Jetpack Compose (Material 3)**
* **Target SDK:** Android 15 (API 36) | Min SDK: Android 8.0 (API 26)
* **Design System:** Kesariya (`#E65100`), Sovereign Gold (`#C9952B`), and Slate Navy (`#0F172A`)
* **Live APIs:**
  - 📮 India Post Pincode Directory API
  - 🌦️ Open-Meteo Farmer Weather & Crop Advisories
  - 🌾 Agmarknet Rajasthan Mandi Live Rates
  - 🛡️ Zero-Crash Offline-First Fallback Architecture

---

# Debug Build
